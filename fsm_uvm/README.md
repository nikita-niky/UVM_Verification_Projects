# About the FSM_uvm file

This includes two folders one for Moore State Machine and other for Mealy State Machine.
Each of them have Seperate README.md file please refer those for that specific state machine.
Below is the Comparision Table for Moore and Mealy Machine . 



## Moore vs. Mealy: A Portfolio Comparison

|Feature|Moore |Mealy |
| :---: | :---: | :---: |
|State Count           |5 States                  |4 States (Hardware Efficient)|
|Output Timing         |Registered (1 cycle delay)|Combinational (Immediate)|
|Verification Challenge|Simpler State Tracking    |High risk of False Positives/Glitches|
|Overlap Logic         |Non-Overlapping           |Fully Overlapping|
